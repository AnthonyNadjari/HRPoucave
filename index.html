Connecter le dépôt

Les fiches et captures sont enregistrées dans un dépôt GitHub privé, à vous. L'application y lit et écrit directement : tout est dans git, accessible depuis tous vos appareils.

Créer le dépôt et le token (2 minutes)
  1. github.com/new : nom CarnetData, visibilité Private, créer.
  2. Fine-grained token : expiration la plus longue, Repository access → Only select repositories → CarnetData, Permissions → Contents → Read and write. Générer, copier.
  3. Coller le token ci-dessus. Il reste dans ce navigateur uniquement.
